# Pie Safe Browser Extension

## Installing in Chrome (developer mode)

1. Open Chrome and go to `chrome://extensions`
2. Enable **Developer mode** (top right toggle)
3. Click **Load unpacked**
4. Select this `extension/` folder
5. The Pie Safe icon appears in your toolbar

## Usage

1. Navigate to any recipe page
2. Click the Pie Safe icon
3. Preview the extracted recipe
4. Click **Save to Recipe Box**

## Requirements

- Must be logged into pie-safe.com in the same browser
- Works on any recipe page with structured data (NYT Cooking, Serious Eats, etc.)
- Falls back to Claude parsing for sites without structured data

## Icons

Replace the placeholder icons in `icons/` with real 16×16, 48×48, and 128×128 PNGs before distributing.
