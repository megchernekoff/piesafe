Pie Safe

Product & Technical Summary — November 2026

What It Is

Pie Safe is a personal meal planning web app designed around the full cooking lifecycle: discovering and saving recipes, planning a week of dinners, and generating a grocery list — all in one place. It is built for households (families, couples, individuals) who cook regularly and want less friction between “what should we eat this week?” and actually eating it. It has a particular focus on households with toddlers, offering adapted meal suggestions alongside adult versions.

What It Does Today

Recipe Box

  • Save recipes from any URL — Claude parses the page and extracts structured recipe data
  • Upload a photo of a cookbook page or recipe card — Claude reads and saves it
  • Describe a dish in plain text and Claude generates a full recipe (ingredients, steps, timing)
  • Chrome extension for one-click saving from any recipe site, including paywalled ones
  • Full recipe library with search, tags, and time estimates

Meal Planning

  • AI-generated 5–7 night dinner plans, tailored to household size, dietary restrictions, dislikes, and free-text tweaks (“nothing too heavy,” “use up the pork in the fridge”)
  • Pin specific recipes from your box to guarantee they appear in the plan
  • Placeholder meals (e.g. “pizza night”) can be named and locked in
  • Toddler mode adds kid-friendly adaptation notes to every meal
  • Swap individual nights without regenerating the whole plan
  • Conversational plan refinement via chat

Grocery List

  • Auto-generated from the meal plan, organized by category (produce, dairy, etc.)
  • Add custom items, check off and restore items; persists between sessions

The Digest

  • Connects to Gmail (read-only OAuth) and scans food newsletters the user subscribes to
  • Supported sources: NYT Cooking, Bon Appétit, Serious Eats, Smitten Kitchen, Epicurious, Food52, Half Baked Harvest, Ina Garten, The Kitchn, Budget Bytes, King Arthur Baking, Simply Recipes, and more
  • Surfaces recipes from newsletter emails; users save individual recipes directly to their Recipe Box
  • Newsletter onboarding on the Digest page — users mark what they already subscribe to or link out to sign up

Onboarding

  • Welcome screen → guided 9-step product tour (Recipe Box, Meal Plan, Digest)
  • Starter recipe picker: swipe-based card UI (“dating app style”) showing 10 curated recipes sampled across categories, filtered by dietary preferences
  • Gift recipe from the founder (Orange Glazed Chicken Breast) added automatically on first visit
  • Digest nudge tooltip after onboarding, reminding new users to connect their inbox
  • All onboarding state is scoped per user so multiple accounts in the same browser behave independently

User Preferences & Account

  • Household size, dietary restrictions (vegetarian, vegan, gluten-free, dairy-free, nut-free, halal, kosher), ingredients to avoid
  • Toddler mode with age in months
  • Full account deletion: wipes all user data from the database and deletes the account

Room for Growth

Near-Term Product

  • Mobile-optimized experience / native app (currently web-only, responsive but not native)
  • Recipe rating and personal notes (“made this, would add more lemon next time”)
  • Pantry / “what’s in the fridge” mode that generates plans around existing ingredients
  • Meal history to avoid repetition across weeks
  • Recipe scaling (adjust servings dynamically)
  • Nutritional estimates per meal and per week

Monetization

  • Freemium tier: free for basic recipe box and limited plan generations; paid for unlimited AI use, Digest, and advanced features
  • Household / family plan: shared recipe box and meal plans across multiple users
  • Grocery delivery integration: Instacart, AmazonFresh, etc. from the grocery list
  • Newsletter partnerships: featured onboarding placements with referral arrangements

Platform Expansion

  • Voice: “What’s for dinner tonight?” via Alexa / Google Home, reading from the active plan
  • Sharing: publish a recipe or week’s plan publicly or to a specific person
  • Community layer: save recipes others have published, follow cooks you trust
  • API for third-party integrations (smart fridges, grocery apps)

How It Works — Technical

Stack

  • Framework: Next.js 16 (App Router, TypeScript — server and client components)
  • Auth: Clerk v7 — sign-up, sign-in, session management. All data scoped to Clerk user_id.
  • Database: Turso (hosted libsql / SQLite-compatible). Schema managed in code via idempotent CREATE TABLE IF NOT EXISTS with additive ALTER TABLE migrations.
  • AI: Anthropic Claude API (claude-sonnet-4-6) — recipe parsing from URLs, photo OCR and extraction, freeform recipe generation, and streaming meal plan generation.
  • Deployment: Render (web service). Custom domain pie-safe.com.
  • Extension: Chrome Web Store extension for one-click recipe saving from any browser tab.

AI Integration

  • Meal plan generation streams via ReadableStream to avoid the 30-second hosting timeout. The client consumes the stream and the plan is parsed and saved to the database once streaming completes.
  • Recipe import from URL sends page content to Claude and gets back structured JSON (title, ingredients, instructions, timing).
  • Recipe from photo uses Claude’s vision capability — image is uploaded and sent as base64.
  • Recipe from description is a prompt-to-structured-JSON generation.
  • Digest parsing scans Gmail via the Gmail API and sends email body to Claude for recipe extraction.
